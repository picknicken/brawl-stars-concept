# Arena Brawlers

Prototype van een Brawl Stars-achtige 3v3 arena-game in 3D (three.js, toon-shading + outlines; eigen namen en art).

Speel: open `index.html` in een browser (of `npx http-server`).

- Modus: Gem Grab 3v3 tegen bots, houd 10 gems vast tot de timer afloopt
- 3 brawlers: Blaze (shotgun), Bolt (sniper), Boulder (tank), elk met een Super
- Ammo, Super-lader, struiken, respawn, respawn-gems
- Besturing: WASD + muis (klik = schieten, spatie = Super) of touch-joysticks

Volgende stappen: meer modi (Brawl Ball, Showdown), betere bot-AI, meer brawlers, progressie, online multiplayer.
